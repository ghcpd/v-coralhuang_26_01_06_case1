## 📋 Behaviors & decisions (brief)

- parse_size supports:
  - Decimal units (kB, MB, ... base 1000)
  - Binary units (KiB, MiB, ... base 1024)
  - GNU single-letter suffixes (`K`, `M`, ...) — ambiguous, resolution controlled by:
    - `strict=True` & `default_gnu=False` → ambiguous single-letter suffixes raise `ValueError`
    - otherwise resolved using `default_binary` (1024 if True, 1000 if False)
  - Optional whitespace and mixed case
  - Fractional values and rounding modes: `floor`, `nearest`, `ceil`
    - `nearest` uses halves-away-from-zero (e.g., 1.5 → 2, -1.5 → -2)
  - Optional thousands separators `,` and `_` when `allow_thousands_separator=True`
- Error handling:
  - Empty string, NaN, Inf, unknown unit, malformed input → `ValueError`
  - Negative values: rejected when `strict=True`, accepted when `strict=False`
  - Extremely large values that become infinite are rejected

All these behaviors are documented in README.md and covered by tests.
