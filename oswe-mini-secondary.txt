## Key implementation details 🔧

- parse_size(text, *, default_binary=False, default_gnu=False, allow_thousands_separator=False, rounding='nearest', strict=True) -> int
  - Accepts numeric strings (supports decimals and scientific notation).
  - Supports decimal units kB/MB/... (1000^n) and binary KiB/MiB/... (1024^n).
  - Supports GNU single-letter suffixes K/M/G/T/P. If `default_gnu=False` and `strict=True`, single-letter suffixes are treated as ambiguous and raise `ValueError`. If permissive (`strict=False`) or `default_gnu=True`, they are resolved using `default_binary`.
  - `allow_thousands_separator` lets `,` and `_` appear in numbers (otherwise raises `ValueError`).
  - Fractional values are supported; `rounding` controls conversion to integer bytes: `floor`, `nearest` (ties away from zero), `ceil`.
  - `strict=True` rejects negative sizes and ambiguous GNU units; `strict=False` permits negatives and resolves ambiguity using `default_binary`.
  - Invalid inputs (empty string, nan/inf, unknown units) raise `ValueError`.

- naturalsize behavior preserved:
